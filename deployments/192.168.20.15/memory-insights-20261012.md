# 企业微信个人记忆与问答统计 V1

部署日期：2026-10-12。环境：`192.168.20.15`，空间：`fangshaoyu's Workspace`。

## 用户怎么使用

空间已开启长期记忆，沿用现有提炼模型和 bge-m3 向量模型。企业微信用户不需要注册 Web 账号；身份按“空间 + 机器人渠道 + 企业微信用户 ID”隔离，同一渠道内私聊和群聊识别为同一个人，不同用户分开。

在小济的**私聊**中使用：

| 发送内容 | 作用 |
| --- | --- |
| `我的记忆` | 查看当前个人记忆和生效状态；下一页可发 `我的记忆 2` |
| `记住：偏好：回答先给结论再给步骤` | 明确保存回答偏好 |
| `记住：我主要负责 KE 平台部署` | 明确保存个人事实 |
| `确认记忆 编号` / `拒绝记忆 编号` | 处理待确认条目，编号来自“我的记忆” |
| `删除记忆 编号` | 删除自己的指定记忆 |
| `暂停记忆` / `恢复记忆` | 暂停或恢复个人记忆的提炼和使用 |
| `清空我的记忆` | 返回一次性确认码，确认后清空个人记忆；不会删除聊天或知识库 |

普通问答也会按空间设置异步提炼。当前设置为延迟 90 秒、最小间隔 300 秒，可能更晚完成；不是每一句话都会保存。推测性的内容需确认后生效。

群聊只允许召回当前提问者的回答偏好，不召回其私人事实、常用资料或检索偏好；查看和修改记忆只在私聊开放。只把当前发送者自己的新问题作为提炼来源，不把机器人回答、引用内容或其他人的话当作此人的事实。

暂停记忆不会停止管理员的问答统计。清空和暂停会建立时间边界，已排队的旧提炼任务不能把清空前的内容写回来。用户记忆也不会作为知识库的权威答案。

## 管理员怎么使用

左侧新增与“回答反馈”同级的 **问答统计** 菜单，入口：

<http://192.168.20.15/platform/qa-insights>

只有空间管理员可以访问，接口同样校验权限。

- **高频问题**：默认最近 7 天，同主题至少 3 次提问、至少 2 个不同身份；可关闭高频限制查看全部主题。
- **问答明细**：查看新发生的原始提问、来源、提问人、每次实际回答、模型、引用、生成状态、反馈和记忆使用条数。
- 在明细中选择两条问答，可并排比较回答；查看和返回使用独立页面，保留原筛选、页码及列表位置。
- 主题支持人工合并、把选中的问题拆为新主题。主题只是统计分组，不等同于标准答案。
- 对回答发起纠错后，进入已有的审核、草稿、回归与发布流程。不会自动发布到 XBROTHER 或覆盖原文档。
- 页面显示企业微信记忆人数、有效条目和提炼任务概况；不集中展示每个人的私人记忆内容。

提问人姓名沿用现有平台用户和企业微信姓名映射；没有映射的企业微信用户继续显示 ID，本次不会凭 ID 猜姓名，也不会自动绑定 Web 账号。

## 本版边界

- 只记录升级后进入问答流程的新问题，不回填旧聊天，不从历史群聊推断个人记忆。
- 管理记忆的命令不计入问答统计。问答前的队列拒绝或附件处理失败尚不属于本版归档范围。
- 问题优先按规范化文本归类；有向量模型时，在同版本/错误码约束下保守合并相似主题。只比较最近 500 个符合条件的自动主题，模糊的截图提问等保留为“未归类”。归类并不保证等同人工理解，可手工调整。
- 向量不可用时退回文本归类，不阻塞回答；已按文本完成的归类不会自动重新计算。
- 问答人数按身份去重，企业微信和 Web 未绑定时会算不同身份。消息重试不重复计问题，但保留回答尝试。
- 企业微信发送状态“已提交，未确认送达”表示发送调用完成，不代表客户端已读。生成失败、截断和中断分开记录。
- 复用现有提炼模型可能产生少量模型调用费用；bge-m3 使用现有本地部署，没有新增模型采购。
