# 回答反馈工作台部署说明

入口：`http://192.168.20.15/platform/answer-feedback`。

## 使用方法

- 管理员在主菜单点击“回答反馈”，默认查看“无用、待处理”。可按评价、处理状态、来源、反馈人、问题关键词和日期筛选；列表支持分页。
- 点击“查看”打开详情。列表不展开完整答案，详情显示问题、原回答、反馈说明、引用知识和处理记录。
- 有用反馈默认提供“标记已阅”；确需纠错时先点击“转入纠错处理”，保留用户的有用评价。
- 无用反馈可创建纠错草稿，选择知识库，编辑标准答案，保存、运行检查，再发布。
- 编辑器支持标题、粗体、斜体、列表、引用、表格、代码块、链接和图片链接，并可切换 Markdown。当前图片通过长期可访问的 HTTP/HTTPS 地址插入。
- 修改已测试的答案会使测试结果失效；必须重新测试才能发布。服务端也验证实际发布内容与测试内容一致，旧版直接发布接口不能跳过检查。
- 已发布详情显示标准答案和版本关系。新增纠错知识不会改写上传的原始文档；存在旧纠错版本时沿用版本替代、回滚机制。

## 权限和检查边界

主菜单、页面路由和全部 11 个管理接口均限制工作空间管理员/所有者访问。普通用户仍从 Web 或企业微信回答下提交评价，不进入管理工作台。管理接口始终执行权限检查，不受通用 RBAC 灰度开关影响，也不接受普通 API Key 代替人工管理员。

当前沿用的“回归测试”是答案文本覆盖检查，不是事实真伪自动判定，也不代表已经对真实问答做语义正确率评估。页面会明确提示管理员核实业务事实。
