# 员工记忆管理与纠错问答回归

## 本次范围

- 问答统计新增员工记忆入口，按企业微信身份展示个人开关、生效/待确认条数、待提炼会话、异常与最近提炼时间。
- 详情采用独立页面，返回列表保留关键字与页码；长文本省略，使用组件提示。
- 普通管理员默认只看运行状态。空间所有者可单独授予、撤销正文查看权限；正文读取必须填写原因，并在同一事务中写审计。审计失败不返回正文，审计本身不保存正文。
- 新问答保存记忆调用原因、模式、候选数与使用数。旧问答标为未记录，不能追溯推断。群聊保持仅使用提问者偏好，私聊仍按员工隔离。
- 纠错发布前执行真实检索并临时加入候选草稿，生成真实回答，再检查引用、必含/禁含短语和模型事实评估。预演不写入知识索引。
- 发布后可执行真实索引复验，要求引用已发布新版本且不引用被替代的纠错版本。预演通过不等于索引复验通过。
- 测试记录持久化，可离开页面后继续查看。每轮原问题加变体最多 5 个，每题限时；异常、截断、评估失败均不视为通过。
- 测试隔离聊天历史和个人记忆，关闭联网与数据分析，仅检索目标知识库；不发送企业微信消息、不产生普通问答统计或员工记忆。

## 操作入口

1. 管理员：问答统计 → 员工记忆与诊断 → 查看。
2. 所有者：员工记忆 → 记忆正文查看授权；授权后在详情输入原因，再查看正文。
3. 问答统计 → 问答明细 → 查看 → 记忆调用诊断。
4. 回答反馈 → 处理 → 纠错草稿 → 运行问答预演；通过后人工核实，再发布。
5. 新版本发布并完成索引后，在该反馈详情点击运行真实检索复验。

## 边界

- 本轮未做企业微信与 Web 账号自动绑定。备注姓名只是显示名，不代表身份绑定。
- 未默认给任何管理员授予私人记忆正文查看权限。管理员只读，员工通过私聊命令管理个人记忆。
- 旧版直接发布、没有纠错版本记录的历史知识不会被自动转换。
- 回归使用所选快速问答智能体的模型、提示词和检索参数，针对目标知识库做隔离测试，不模拟历史会话或企业微信发送。
- 模型事实评估是审核辅助，不能保证业务事实永远正确；短语检查为严格匹配。测试使用现有模型额度。
- 发布后索引复验由管理员发起，不自动回滚已发布知识。
